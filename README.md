> **研習主題**：115基隆科技團-資訊非專研習-AI Agent 行政實戰  
> **線上成果展示**：[點此開啟 GitHub Pages 成果展示首頁](https://yaoshuchin.github.io/115-keelung-ai-agent-workshop/)  
> **講義與教材中樞**：[mihozip.tw 研習講義與工具工作台](https://mihozip.tw/lectures.demo/2026101623-keelung/)

## 📌 研習梯次與課程規劃

本研習採雙梯次循環、累計 6 小時實戰：

- **第一梯次**：115 年 10 月 16 日 (五) 13:30–16:30（前 3 小時：概念 × 規格 × 工具）
  - 單元一：打破 Prompt 迷思（從打字問答到自主智慧代理）
  - 單元二：任務規格化實戰（教務處與學務處 Agent Brief）
  - 單元三：多檔案清洗與工具調用（行政表單與去個資自動化）
- **第二梯次**：115 年 10 月 31 日 (六) 13:30–16:30（後 3 小時：專案 × 實戰 × 防護）
  - 單元四：專案狀態持久化管理（`PROJECT_STATE.md` 狀態接關機制）
  - 單元五：三大處室自動化工作流閉環（Plan-Execute-Review 規劃、執行與自檢）
  - 單元六：可信任智慧代理與安全護欄（人工審查雙軌制與安全防護線）

---

## 📊 研習亮點大數據

- **參訓總人次**：雙梯次累計 **165** 人次（梯次一 109 人、梯次二 56 人）
- **深度回饋達標率**：**133** 位教師心得超過 100 字（達標率達 **80.6%**）
- **全國服務縣市**：涵蓋 **17** 個縣市（新北、台北、台中、高雄、屏東、台南、基隆、雲林等）
- **涵蓋單位學校**：超過 **90 所** 各級公私立高國中小、大專院校與機關

## 🛡️ 個人資料保護與去識別化規範

本開源成果網站已全面遵循個人資料保護法之合規要求：
- **學員姓名**：嚴格去識別化，僅保留姓氏，其餘全部以「0」遮罩替換（例：`洪00`、`陳00`、`E00000`）。
- **身分證字號**：完全省略，不於任何公開網頁中載錄。
- **原始試算表**：所有包含原始名冊與聯絡方式之 Excel 檔案（`*.xlsx`）皆透過 `.gitignore` 排除，絕不上傳至公開儲存庫。
